# 森罗物语：牧场 / Kaleidoscope: Ranch

---

## 简介

本模组为 家畜/家禽类动物 添加了一套农场机制。

通过 kaleidoscope_ranch:poultry 标签判断动物是否为家禽。
通过 kaleidoscope_ranch:livestock 标签判断动物是否为家畜。
通过 kaleidoscope_ranch:managed_animal 标签判断动物是否为家禽和家畜。

## 功能概述

### 机制范围

#### 心情值范围
- 初始心情值：100
- 最低心情值：0
- 最高心情值：120

---

## 心情值提升因素

### 1.空手抚摸
* 触发条件：空手右键点击动物
* 限制：每只动物每天只能抚摸一次
* 效果：心情值 +1

### 2.盐块增益
* 触发条件：动物 4 格范围内存在盐块
* 效果：心情值 +1
* 检查频率：每 4 分钟检查一次

### 3.自然恢复
* 触发条件：动物当前没有任何心情值下降因素生效时，且心情值低于初始值
* 效果：心情值 +1
* 检查频率：每 3 分钟检查一次

## 心情值降低因素

### 1.多物种混养
* 触发条件：动物4格范围内存在3种及以上不同种类的动物
* 效果：心情值 -1
* 检查频率：每 3 分钟检查一次

### 2.粪便污染
* 触发条件：动物8格范围内存在粪便
* 效果：心情值 -2 x 附近粪便数量
* 检查频率：每 3 分钟检查一次

### 3.雨天淋雨
* 触发条件：下雨天气且动物所在位置可以看到天空
* 效果：心情值 -1
* 检查频率：每 20 秒检查一次

### 4.受伤惩罚
* 触发条件：动物受到任何伤害
* 效果：心情值 -10
